## Field naming note

`puja.json`'s existing `mediaType` field was left untouched (still controls audio/text/video rendering in `PujaScreen.jsx`). `imageFile` holds a single filename (matches the existing `audioFile`/`videoFile` naming convention); `imageFiles` (new, plural) holds an array and is only present on the two multi-panel कथा steps. Both are now rendered by the `StepImage` component in both नियंत्रक and दर्शक modes. `videoIsLocal: true` is a new boolean (only on s14-01 so far) telling `VideoPlayer` to serve the file from the site's own `public/` folder instead of the R2 CDN.
